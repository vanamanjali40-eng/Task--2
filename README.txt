# Task 2: Data Visualization and Storytelling

## Files
- `superstore.csv` – sample sales dataset
- `data_visualization.py` – Python program for Pydroid 3
- The program creates four charts: monthly sales trend, category sales, profit by region, and category sales share.

## Run in Pydroid 3 (Android)
1. Install **Pydroid 3** from Google Play.
2. Open Pydroid 3 and install the packages `pandas` and `matplotlib` using its Pip menu.
3. Extract this ZIP file.
4. In Pydroid 3, open `data_visualization.py`.
5. Keep `superstore.csv` in the same folder as the Python file.
6. Tap the yellow Run button.
7. View the charts and the business insights printed in the output.

If Pydroid asks for permission to access files, allow it.

## Project objective
Create charts that explain sales performance and communicate useful business insights.

## Chart explanations
1. **Monthly Sales Trend (Line Chart):** shows how sales change month by month.
2. **Sales by Category (Bar Chart):** compares revenue from Furniture, Technology, and Office Supplies.
3. **Profit by Region (Bar Chart):** compares profit across North, South, East, and West.
4. **Category-wise Share (Pie Chart):** shows each category's percentage contribution to total sales.

## Storytelling / business findings
Use the exact figures printed by the program after running it. The highest sales category, highest-profit region, best month, and lowest-profit region are printed automatically.

## Submission
Submit the Python file, CSV dataset, four generated chart images, and a short PDF/report describing the insights. This sample dataset is created for practice and is not official company data.
